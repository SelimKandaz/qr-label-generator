# Open Source Notes

This repository includes the sanitized QRCC v1.3.0 desktop application source code.

## Removed or generalized

- Company-specific branding was changed to generic open-source wording.
- Generated output folders remain ignored by Git.
- Sample data is fake.

## Safe to publish

- Source code
- README/docs
- Fake CSV sample data
- User guide

## Do not publish

- Real asset batches
- Customer records
- Purchase-order data
- Internal labels or generated production PDF sheets
